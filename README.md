# this week on wikipedia

```text
+----------------------------------+
|      THIS WEEK ON WIKIPEDIA      |
+----------------------------------+
| 01  MUSIC                        |
| 02  MOVIES                       |
| 03  TV                           |
| 04  CELEBRITIES                  |
| 05  INTERNET CULTURE             |
| 06  SPORTS                       |
| 07  POLITICS                     |
| 08  CURRENT EVENTS               |
+----------------------------------+
```

a weekly ranking of what people are reading, who they're looking up, and the subjects the internet suddenly decided it needed to understand this week on wikipedia.

originally concepted as a quieter alternative to the algorithmic feed, built around collective curiosity instead of personalized recommendations.

methodology: it tracks views across wikipedia's top 1,000 pages and ranks the top 10 across music, movies, tv, celebrities, internet culture, sports, politics, and current events.
